# Titanic EDA using Python

## Overview
This repository contains Task 5 of the Elevate Labs Data Analyst Internship program. The objective of this task was to perform Exploratory Data Analysis (EDA) on the Titanic dataset using Python and visualize important patterns, trends, and relationships that influenced passenger survival.

## Objective
- Understand the dataset structure
- Clean and prepare data for analysis
- Perform univariate and bivariate analysis
- Identify patterns affecting survival
- Visualize findings using charts and graphs
- Generate meaningful business insights

## Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The Titanic dataset contains passenger information including:
- Passenger Class
- Gender
- Age
- Fare
- Embarkation Port
- Family Information
- Survival Status

## Data Cleaning Performed
- Checked for missing values
- Handled null values
- Removed duplicate records
- Corrected data types
- Verified data consistency

## Exploratory Data Analysis

### Univariate Analysis
- Survival Distribution
- Gender Distribution
- Passenger Class Distribution
- Age Distribution
- Fare Distribution

### Bivariate Analysis
- Gender vs Survival
- Passenger Class vs Survival
- Embarkation Port vs Survival
- Age vs Survival
- Fare vs Survival

### Additional Analysis
- Outlier Detection using Boxplots
- Correlation Heatmap
- Feature Relationship Analysis

## Key Findings
- Female passengers had significantly higher survival rates than males.
- First-class passengers were more likely to survive than third-class passengers.
- Higher ticket fares were associated with better survival chances.
- Most passengers were between 20 and 40 years old.
- Passenger class and fare showed the strongest relationship with survival.
- Age had a relatively weak impact on survival compared to gender and class.
